# Reglas del juego (PDF)

PDF oficiales del juego (reglamentos, guías de campaña y FAQ). El repositorio es
privado y de uso personal, así que **se suben a git** para poder consultarlos al
desarrollar en cualquier equipo.

## Qué PDF son útiles (en inglés y en español si los tienes)

| Documento | Para qué sirve |
|---|---|
| **Rules Reference / Guía de referencia** | Fuente principal del motor: glosario, temporización, pruebas de habilidad, secuencia de fases. Imprescindible |
| Learn to Play / Aprende a jugar | Visión general y ejemplos sencillos para los primeros tests |
| Guías de campaña (empezando por la caja básica) | Preparación de escenarios, resoluciones, registro de campaña |
| FAQ / Errata y lista Taboo | Correcciones oficiales y casos límite |

## Uso

- Al implementar una regla, citar la sección en el test.
- La versión en español sirve para fijar la terminología del glosario y de la
  interfaz en castellano.
- No copiar párrafos literales en la aplicación.
