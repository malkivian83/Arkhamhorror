# 72 · Última oportunidad

Lote `exclusive-skills`: **2 códigos / 2 cartas o niveles distintos nuevos / 0 reediciones**: Última oportunidad 0 (04036) y 3 (11093). El tamaño responde a la mecánica nueva de compromiso exclusivo y pérdida dinámica de iconos.

Ambas requieren una prueba sin cartas comprometidas e impiden añadir cartas propias o de ayudantes, incluso desde descartes. El nivel 0 parte de cinco comodines; el nivel 3, de seis. Restan un comodín por cada carta en la mano de quien las comprometió, incluidas debilidades y otras copias, con mínimo cero. La previsualización excluye únicamente la copia que abandona la mano; desde descartes cuenta toda la mano. El nivel 3 roba dos cartas para quien la comprometió solo tras el éxito, mientras siga comprometida.

El motor incorpora `exclusiveCommit` y el contexto de zona para iconos dinámicos. Habitación 245, Isabelle y el compromiso desde la parte superior del mazo pasan la zona correcta. Conserva el requisito de iconos coincidentes: una mano que suprima todos los comodines impide comprometer la carta.
