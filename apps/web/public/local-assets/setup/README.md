# Imágenes de preparación

Recursos de Fantasy Flight Games utilizados por el proyecto de referencia
`D:/referencia/ArkhamHorror-main`, importados el 19 de octubre de 2026.
Se guardan en local para que la portada no dependa de peticiones al CDN.

La referencia resuelve las portadas con `campaignBox` y `scenarioBox` en
`frontend/src/arkham/helpers.ts`; su inventario figura en
`frontend/image-manifest.json` y el CDN se configura en `frontend/src/stores/site_settings.ts`.
