# Narraciones de historia

Lecturas en voz alta del texto oficial de la guía de campaña, generadas con
ElevenLabs (voz «Gabo - Deep, Evocative and Resonant») el 20 de octubre de 2026.
La mesa las ofrece desde `apps/web/src/game/narration.ts`, que asocia cada
fichero a la clave i18n del texto que lee.

| Archivo                               | Texto                                                  |
| ------------------------------------- | ------------------------------------------------------ |
| es/brethren-of-ash-prologue.mp3       | Prólogo de Los Hermanos de la Ceniza                   |
| es/spreading-flames-intro.mp3         | Introducción del escenario I, Spreading Flames         |
| es/spreading-flames-no-resolution.mp3 | Sin resolución del escenario I, Spreading Flames       |
| es/smoke-and-mirrors-intro.mp3        | Introducción del escenario II, Smoke and Mirrors       |
| es/queen-of-ash-intro-1.mp3           | Introducción 1 del escenario III, Reina de las cenizas |
| es/queen-of-ash-intro-2.mp3           | Introducción 2 del escenario III, Reina de las cenizas |
| es/queen-of-ash-intro-3.mp3           | Introducción 3 del escenario III, Reina de las cenizas |

El texto narrado conserva los derechos de sus propietarios, igual que el resto
de textos del juego incluidos en este proyecto personal no oficial.
